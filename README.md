# GEOLEADER — сайт-презентация

React + Vite + TypeScript + Tailwind CSS (v4).

## Запуск

```bash
npm install
npm run dev
```

Сборка для продакшена:

```bash
npm run build
```

## Что нужно доделать

- **Видео в hero-секции**: положите файл в `public/hero.mp4` (короткий, зацикленный
  ролик — дрон/пейзаж региона). Если видео нет или оно не загрузилось, автоматически
  показывается анимированный контурный фон (см. `src/components/Hero.tsx`), так что
  сайт не «сломается» без ролика.
- **Логотипы двух программ** в hero — сейчас это заглушки `LOGO`, замените на
  реальные изображения в `LogoBadge` (`src/components/Hero.tsx`).
- **Показатели эффективности** (`src/components/Metrics.tsx`) — сейчас нули,
  подставьте реальные цифры (или подключите к бэкенду/таблице, когда появится).
- **Медиа-секция** (`src/components/Media.tsx`) — плейсхолдеры под фото/видео с
  полевых исследований учеников.

## Структура

```
src/
  styles/fonts.css   - шрифты (Instrument Serif + Inter)
  styles/theme.css   - цвета, анимации (fade-rise)
  components/
    NavBar.tsx
    Hero.tsx               - видео-фон с плавным зацикливанием (по вашему промпту)
    About.tsx              - "Жоба туралы" / Мақсаты
    Results.tsx            - "Күтілетін нәтиже" (4 карточки)
    Metrics.tsx            - показатели платформы
    Interdisciplinary.tsx  - "Пәнаралық интеграция" (карусель, переворот при наведении)
    Quote.tsx              - "Дәйексөз"
    Media.tsx              - "Медиа"
    Footer.tsx
```

Секции и навигация соответствуют структуре из Сайт_құрылымы.docx.
